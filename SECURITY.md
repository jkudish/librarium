# Security policy

Please report security issues privately. Don't open a public issue.

- Email [joey@jkudish.com](mailto:joey@jkudish.com), or
- use [GitHub private vulnerability reporting](https://github.com/jkudish/librarium/security/advisories/new).

Include the affected version, steps to reproduce, and the impact you found. Fixes ship in the latest release of `librarium`.
